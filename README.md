## 📂 Projets

### 🌾 [AgriYield — Impact du changement climatique sur les rendements céréaliers](https://github.com/Kattie19/AgriYield-Econometrics)

> Projet tutoré M1 · Économétrie de données de panel · R

Analyse économétrique de l'impact des conditions climatiques sur la production
de blé, maïs et orge en **Europe du Sud** (6 pays, 2003–2022, N = 360).

- Modèles **effets fixes** (within) avec interactions par culture
- Variables : température², précipitations, taux d'irrigation, engrais
- Données publiques : FAOSTAT · Eurostat · Berkeley Earth · World Bank WDI
- Résultat clé : l'irrigation booste significativement le maïs (+1.1% par point d'irrigation, sig. 5%)

**Stack :** `R` · `plm` · `ggplot2` · `stargazer` · `LaTeX`  
[📁 Voir le dépôt](https://github.com/Kattie19/AgriYield-Econometrics) · 
[📄 Lire le rapport (PDF)](https://github.com/Kattie19/AgriYield-Econometrics/blob/main/reports/Rapport_AgriYield_2025-2026.pdf)
